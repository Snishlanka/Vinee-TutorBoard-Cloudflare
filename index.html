Mathematics

One function per line (up to 4). Examples: x^2, 2x+1, sin(x), sqrt(x), 1/x. Trigonometric functions use radians.

Leave functions empty to insert only a coordinate grid. Axes appear when zero is inside the selected range.

Separate names with commas, such as P, Q, R. Leave empty for default labels. For circles and angles, the first name labels the centre or vertex.

Diagrams use your current chalk color and width. Use Move to position them, and Text or Chalk to add side lengths and explanations.

    Install TutorBoard

    Open the app online once and wait for Ready offline. Then drawing, images, graphs, lesson files and PDF exports work without an internet connection.

    • Microsoft Edge: close this help window, then choose Menu (...) > More tools > Apps > Install this site as an app. If TutorBoard is already installed, enter edge://apps in the address bar and open it there.
    • Chrome: use the install icon in the address bar or the browser menu.
    • iPhone / iPad: open in Safari, choose Share → Add to Home Screen → Open as Web App / Add.
    • Other browsers can use the website normally; installation options depend on your browser.

    Autosave keeps local drafts. Clearing browser data or removing app data can erase them. Keep downloaded lesson backups. This app does not upload your lessons.
